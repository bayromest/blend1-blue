Blend1 Blue

Follow Star

Blender's .blend1 backup files get a blue Blender icon on Windows, so you stop opening the backup by accident.

Install with updates (recommended)

  1. In Blender, open Edit → Preferences → Get Extensions.
  2. Open Repositories (top right), click +, then Add Remote Repository.
  3. Paste this URL and click Create:
    https://bayromest.github.io/blend1-blue/index.json
  4. Search for Blend1 Blue and click Install.

Or drag and drop

Drag the blend1_blue link below into a Blender window. Blender offers to add this repository too, so you still get updates.
